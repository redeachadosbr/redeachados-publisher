TikTok Developers

No TikTok Developers, habilite Content Posting API e autorize os escopos video.upload e video.publish. Para o modo rascunho, video.upload é o escopo necessário.

Instagram / Meta

O token precisa incluir instagram_basic, instagram_content_publish, pages_show_list e pages_read_engagement. Para produção, prefira salvar INSTAGRAM_ACCESS_TOKEN no Environment do Render.
