Configure META_APP_ID e META_APP_SECRET no Environment do Render. Para publicar e automatizar comentários, o token precisa incluir as permissões do Instagram para publicação, comentários e mensagens. Para Ads, o token usado pela Marketing API precisa de ads_management.
