Política de Privacidade

Última atualização: 26 de setembro de 2026

Esta Política de Privacidade explica como o REDEACHADOS BR Publisher trata informações durante a utilização do aplicativo.

1. Informações processadas

O aplicativo poderá processar informações necessárias para sua operação, incluindo dados de autenticação, informações básicas de contas conectadas e conteúdos enviados pelo próprio usuário.

2. Integração com o TikTok

Quando o usuário conecta uma conta TikTok, o aplicativo utiliza os mecanismos oficiais de autorização disponibilizados pelo TikTok.

O acesso é limitado às permissões autorizadas pelo próprio usuário e necessárias para as funções oferecidas pelo aplicativo.

3. Conteúdos enviados

Vídeos, imagens e outros conteúdos fornecidos pelo usuário podem ser processados para análise, preparação de legendas, descrições, hashtags e publicação autorizada.

4. Compartilhamento de informações

As informações não são vendidas a terceiros. Dados poderão ser transmitidos somente aos serviços necessários para executar as funcionalidades solicitadas pelo usuário, como APIs de inteligência artificial, hospedagem e plataformas de publicação.

5. Segurança

São adotadas medidas razoáveis de segurança para proteger credenciais e informações utilizadas pelo aplicativo.

6. Retenção de dados

As informações são mantidas apenas pelo período necessário para a execução das funcionalidades do serviço ou para cumprimento de obrigações aplicáveis.

7. Exclusão e solicitação de dados

O usuário poderá solicitar informações ou exclusão de dados relacionados ao aplicativo entrando em contato pelo endereço abaixo.
