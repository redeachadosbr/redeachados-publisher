# Atualização V5.5.5 · Política de Privacidade pública

Esta versão parte integralmente da V5.5.4 e não altera o fluxo de publicação, Supabase, Webhook, Direct, TikTok ou Instagram.

## Adicionado

- Página pública de Política de Privacidade em `/privacy`.
- Alias `/privacy-policy` para compatibilidade com cadastros externos.
- Alias `/data-deletion` exibindo as instruções de exclusão de dados da mesma política.
- Link discreto "Privacidade" no rodapé do Publisher.
- A página é pública e não exige a senha do Publisher.

## URL para cadastrar na Meta

`https://redeachados-publisher.onrender.com/privacy`

Em **Meta for Developers → Configurações do app → Básico → URL da Política de Privacidade**, informe a URL acima e salve.

Se a Meta solicitar uma URL de instruções de exclusão de dados, use:

`https://redeachados-publisher.onrender.com/data-deletion`

## Deploy

Substitua os arquivos do projeto no GitHub pelos desta versão e aguarde o Auto-Deploy do Render. Preserve todas as variáveis de ambiente atuais.
