# V5.5.15 — Studio Pro

## Navegação
- Nova página **Link clicável** no menu lateral.
- Nova página dedicada **Canais de conexão** para TikTok e Instagram.
- Histórico passou a abrir como página independente.

## Stories
- **Abrir Story no iPhone** foi removido do fluxo principal.
- O botão agora é **Copiar link do produto** e copia apenas o endereço Shopee.
- **Publicar Story automático** permanece via API oficial e continua sem adesivo de link.

## Visual
- Tipografia Manrope e hierarquia visual reforçada.
- Sidebar, cards, inputs e botões com novo acabamento premium.
- Estados hover/active mais claros e ícones mais destacados.
- Tela de criação ficou menos carregada ao mover configurações secundárias para páginas próprias.

## Compatibilidade
- APIs e integrações existentes foram preservadas.
- Direct automático, Meta Ads, TikTok, Reels e Stories automáticos continuam usando as mesmas rotas de backend.
